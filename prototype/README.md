# ROAMLY — 호텔 QR 로컬 정보·쿠폰 모바일 웹 프로토타입

호텔 종이 지도의 QR로 들어온 외국인 관광객이 주변 장소를 찾고, 하루 한 번 룰렛과 쿠폰으로 제휴 매장을 방문하는 흐름입니다. 귀사 PM이 전달률·스캔율·리딤률과 광고주 리포트를 확인하고, 운영 시트로 콘텐츠를 바꾸는 운영 콘솔도 함께 보여 드립니다.

> 호텔·매장·주소·전화번호·쿠폰·지표는 모두 **시연용 가상 데이터**입니다. 지도는 그림 지도로 대신했으며, 실제 구축 시 Google Maps JavaScript API를 연결합니다. 쿠폰 발급·리딤 규칙은 브라우저에서 서버 규칙처럼 재현했습니다.

## 여는 방법

- 시작 파일은 이 폴더의 `index.html`입니다. 정적 호스팅(GitHub Pages 등)에 폴더 전체를 올리거나 브라우저로 직접 열면 됩니다.
- 첫 화면에서 호텔 카드를 선택하면 해당 호텔 안내로 들어갑니다. 카드의 QR 버튼에서 호텔별 QR을 확인합니다. 휴대폰 스캔에는 휴대폰에서도 접근 가능한 배포 주소가 필요하며, `localhost`·`127.0.0.1`·`file://` 주소는 다른 기기에서 접속할 수 없습니다.
- 화면 크기에 관계없이 오른쪽 아래 **「체험 안내」** 버튼을 누르면 시나리오·시연 시각·네트워크를 바꾸는 패널이 열립니다. 기본 화면에는 체험 패널과 휴대폰 장식 프레임이 표시되지 않습니다.
- 관광객 화면은 영어가 기본이며 상단 지구본 버튼으로 한국어·일본어·중국어로 바꿉니다. 일본어·중국어는 공통 문구까지 번역했고 상세 설명은 영어로 보입니다.

## 시뮬레이션 범위

- **쿠폰·룰렛·리딤**: 매장별 일일 수량 확인·차감, 같은 요청 재시도 시 기존 결과 반환, 1일 1회, PIN 5회 실패 시 5분 잠금, 60초 확인값을 브라우저에서 재현합니다. 실제 구축에서는 서버 트랜잭션이 보장합니다.
- **지도**: 그림 지도이며 위치는 시연용 가상 위치를 씁니다. 길찾기 버튼은 실제 네이버 지도·Google 지도 검색 화면을 엽니다.
- **오프라인**: HTTPS 또는 localhost에서는 서비스 워커가 화면 파일을 저장해 실제로 데이터 없이 열립니다. 파일로 직접 열거나 일반 HTTP 원격 주소로 열면 실제 오프라인 저장 완료로 표시하지 않고 HTTPS 또는 localhost 이용을 안내합니다.
- **지표**: 최근 14일 추이는 가상 수치입니다. 브라우저의 쿠폰 처리 기록과 별도 누적 지표를 함께 사용하며, 이벤트 로그는 최근 600건만 표시합니다. 호텔별 기간 고유 브라우저는 중복을 제거하고, 리딤률은 선택 기간에 발급된 쿠폰의 조회 시점 사용 상태로 계산합니다.
- 지하철은 약 300역 중 44역의 시연 데이터입니다.

## 체험 데이터 유지와 초기화

- 쿠폰·룰렛·즐겨찾기·이벤트·운영 콘솔 변경 사항과 로그인 상태는 이 브라우저의 localStorage(`roamly-demo:2026102901:v1`)에만 저장되어 새로고침 후에도 이어집니다. 서버로 보내지 않습니다.
- 운영 콘솔 로그인 화면 또는 체험 안내 패널의 **「체험 데이터 초기화」**로 처음 상태로 돌아갑니다.

- 딥그린·아이보리 중심 색상, 사진형 대표 이미지 17종, 호텔 선택 화면과 접이식 체험 도구. 생성 프롬프트와 이미지 성격은 `assets/images/README.md`에 기록했습니다.
- 운영 로그인은 실제 시각 기준 30분 만료, 5회 실패 후 5분 잠금입니다. PM은 전체 기능, 광고 리포트 담당은 광고 조회만 이용합니다. 정적 프로토타입의 브라우저 내 접근 제어이며 실제 서버 인증을 대신하지 않습니다.
- 쿠폰 확인값은 발급 세션·쿠폰·발급된 객체에 연결하며 화면 이동 시 무효화합니다. 비활성 쿠폰, 소수·음수 금액, 다른 쿠폰의 확인값, 만료 확인값을 거절합니다.
- 입력 중 시트 전체를 다시 그리지 않아 입력 포커스와 검증 버튼 클릭을 유지합니다. 미검증·미리보기 전 배포는 차단합니다.
- 오프라인 저장은 서비스 워커 준비·필수 파일 저장 완료 후 표시합니다. 이미지와 두 CSS 파일을 포함하며 API 응답을 오프라인 캐시로 대체하지 않습니다. 실제 연결 차단 후 재접속 검사는 별도 검수 환경에서 확인해야 합니다.

## 화면 전환

## 이용 흐름 후속 점검 · 2026-10-29

한국어 장소 상세·쿠폰·택시 카드의 중복 표기를 정리하고 종료 호텔 안내를 자연스럽게 다듬었습니다. 오프라인 저장은 최대 15초 안에 준비·저장이 완료되지 않으면 실패를 안내하고 재시도할 수 있습니다. 저장 중 다른 화면으로 이동하면 늦게 도착한 결과가 현재 화면을 다시 그리지 않도록 했습니다. 총 34건의 자동 검사가 통과했습니다.

## 고급 도구

운영 콘솔의 「쿠폰 · 리딤」 페이지 아래에 「고급 도구 → 동시 발급 시험」을 배치했습니다. 처음에는 접혀 있고, 펼친 뒤 시험을 실행할 수 있습니다. 일반 운영 정보인 쿠폰 수량·룰렛 재고·리딤 기록·PIN 실패 기록을 먼저 보여 줍니다.
